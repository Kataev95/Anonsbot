# 🍬 Anonsbot — HTML-анонс IRISKA 3.0

Отдельный бот для публикации интерактивной HTML-заставки с 10-дневным обратным отсчётом. Исходный **iriska-bot не изменяется**.

## Использование в группах

**Теперь нет автопубликации при запуске.** Бот запускает long polling и ждёт команду администратора группы:

`/start@ИмяВашегоБота` или `/anons@ИмяВашегоБота`

Например, если username бота `AnonsExampleBot`, в группе напишите `/start@AnonsExampleBot`.

1. Добавьте бота в группу и разрешите отправлять сообщения/медиа. Право на закрепление **необязательно**.
2. Разверните проект на Docker-хостинге через `Dockerfile`.
3. Укажите переменные `BOT_TOKEN` и `WIDGET_API_BETA=0`.
4. Желательно указать `CHAT_IDS` — список разрешённых групп через запятую; иначе команду может вызвать администратор любой группы, в которой состоит бот.
5. После появления строки `Ожидаю /start@...` отправьте команду **от администратора группы**.

В личном чате достаточно написать боту `/start`. В личных чатах закрепление не выполняется. Параметр `PRIVATE_TEST_CHAT_ID` теперь не используется для автоматической отправки.

При успехе бот сохраняет ID опубликованного сообщения. Повторная команда той же версии не создаёт дубль. Для нового анонса увеличьте `WIDGET_VERSION` (например, с `2` на `3`). На всех чатах используется одна и та же дата завершения отсчёта — 10 суток после первого запуска либо значение `LAUNCH_AT`.

## Переменные хостинга

| Переменная | Пример | Описание |
|---|---|---|
| `BOT_TOKEN` | `123456:...` | Обязательно; реальный токен храните только в переменных хостинга |
| `CHAT_IDS` | `-100111,-100222` | Разрешённые группы; опционально |
| `WIDGET_API_BETA` | `0` | `0` — обычный API, `1` — экспериментальный beta API |
| `WIDGET_VERSION` | `3` | Версия виджета для предотвращения дублей |
| `LAUNCH_AT` | `2026-11-18T22:00:00+03:00` | Необязательная фиксированная дата окончания |
| `STATE_DIR` | `/data` | Желательно подключить постоянный том с состоянием |

Хостинг должен запускать **один экземпляр** контейнера с этим токеном: Telegram `getUpdates` нельзя одновременно вызывать из двух процессов.

## Известное ограничение Telegram

Ранее ваш бот успешно отправлял HTML-виджет в личный чат, но Telegram отвечал `400 INPUT_MEDIA_WIDGET_NOT_ALLOWED` при попытке отправить тот же HTML в три группы. **Команда `/start` сама по себе не отменяет серверный запрет на отправку виджетов.** Мы добавили запуск по команде для проверки, но нет гарантии, что сервер Telegram разрешит виджет в группе. Если снова будет `INPUT_MEDIA_WIDGET_NOT_ALLOWED`, бот запишет ошибку **только в логах хостинга** (без спама в группу). Повторные команды в течение 120 секунд после ошибки игнорируются.

## Сборка

`Dockerfile` запускает `python -u main.py` на Python 3.12, без сторонних зависимостей. Сам HTML — `widget.html`. Животные могут оставаться неподвижными на некоторых клиентах Telegram; счётчик продолжает обновляться JavaScript, если клиент поддерживает таймеры.

Документация виджетов Telegram: https://github.com/TelegramMessenger/widget-sandbox
